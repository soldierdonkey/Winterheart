# Winterheart: TACZ

**Timeless and Classics Zero, limited to pre-1950s weapons.**

Minecraft 1.20.1 datapack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Hides every gun, ammunition type and attachment in TACZ's default gun pack except the period set.
- Removes the default pack's gunsmith recipes and bonus chest loot.
- Trims the workbench tabs to match.

Winterheart's own gunsmith recipes are in **Winterheart: Recipes**.

## Requirements

- Minecraft **1.20.1**
- **Timeless and Classics Zero**, with `DefaultPackDebug = false` (its default) so its gun pack stays up to date.

## Installation

The Winterheart modpack already includes it. To install it by hand, put the folder or zip in the world's `datapacks/` folder, or in the instance's `datapacks/` folder when the PackFinder mod is installed.
