# Winterheart: Worldgen

**World generation changes that keep the Winterheart world cold and empty.**

Minecraft 1.20.1 datapack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Turns off most vanilla structure sets and those of Philip's Ruins, Gore Edition, Antlers and Butchery.
- Removes Butchery's sulfur ore.
- Adds the snowy `winterheart:spawn_clearing` biome and its biome tags, and keeps streams out of it.

## Requirements

- Minecraft **1.20.1**
- Works with Philip's Ruins, Gore Edition, Antlers, Butchery and Streams Reflowing (mods).

## Installation

The Winterheart modpack already includes it. To install it by hand, put the folder or zip in the world's `datapacks/` folder, or in the instance's `datapacks/` folder when the PackFinder mod is installed.

Structure changes affect only newly generated chunks.
