# Winterheart: Guides Data

**The guide books and lost journal pages of the Winterheart modpack.**

Minecraft 1.20.1 datapack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Defines the guide books, their pages, the lost journal pages and the triggers that unlock them (`data/winterheart/guides/guides.json`).
- The Winterheart: Guides mod re-reads the file while the game runs.

## Requirements

- Minecraft **1.20.1**
- **Winterheart** and **Winterheart: Guides** (mods). The pack does nothing without them.
- The guides refer to content from other mods in the modpack, such as Butchery, Farmer's Delight, Antlers and Immersive Weathering.

## Installation

The Winterheart modpack already includes it. To install it by hand, put the unzipped folder in the instance's `datapacks/` folder, with the PackFinder mod installed.

The guides mod reads this file from the unzipped folder `datapacks/winterheart_guides/`, so it must be installed there under that name.
