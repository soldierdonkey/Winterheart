# Winterheart: Structures Data

**The hand-built structures of the Winterheart modpack.**

Minecraft 1.20.1 datapack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Contains the watchtower, iceberg shipwreck and summit beacon templates.
- Sets where each one is placed, once per world, and how it sits in the terrain.

## Requirements

- Minecraft **1.20.1**
- **Winterheart** and **Winterheart: Structures** (mods), to place them.
- Mods whose blocks the structures use, including Immersive Weathering, Hardcore Torches, Macaw's Bridges, Macaw's Stairs, Timeless and Classics Zero and Butchery.

## Installation

The Winterheart modpack already includes it. To install it by hand, put the folder or zip in the world's `datapacks/` folder, or in the instance's `datapacks/` folder when the PackFinder mod is installed.

The placement coordinates are made for the Winterheart painted world.
