# Winterheart: Spawning Data

**Tuning for Winterheart's scripted mob spawner.**

Minecraft 1.20.1 datapack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Sets mob templates, spawn pools, hostile mob limits, livestock quotas and wendigo days (`data/winterheart/spawning/config.json`).
- Hostile mobs increase and livestock grows scarce as the days pass.

## Requirements

- Minecraft **1.20.1**
- **Winterheart** and **Winterheart: Spawning** (mods). The pack does nothing without them.
- **Antlers** and **Gore Edition** (mods), for some of the spawned mobs.

## Installation

The Winterheart modpack already includes it. To install it by hand, put the folder or zip in the world's `datapacks/` folder, or in the instance's `datapacks/` folder when the PackFinder mod is installed.
