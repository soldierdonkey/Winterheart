# Winterheart: Painted World

**The hand-painted overworld of the Winterheart modpack.**

Minecraft 1.20.1 datapack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Replaces the overworld generator with a NovoAtlas image map.
- Contains the 4096 x 4096 height map, the biome map and their settings.

## Requirements

- Minecraft **1.20.1**
- **NovoAtlas** (mod).
- The **Winterheart: Worldgen** datapack, which defines the `winterheart:spawn_clearing` biome.

## Installation

The Winterheart modpack already includes it. To install it by hand, put the folder or zip in the world's `datapacks/` folder, or in the instance's `datapacks/` folder when the PackFinder mod is installed.

Applies to new worlds only. It replaces `minecraft:overworld`, so it conflicts with any other pack or mod that does the same.
