# Winterheart: Recipes

**Winterheart's crafting, smelting and gunsmithing recipes.**

Minecraft 1.20.1 datapack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Replaces vanilla tool and armor recipes and the brewing stand recipe with ones built from metal parts.
- Adds recipes for metal parts, saltpeter, gunpowder and chainmail armor.
- Adds TACZ gun smith table recipes for period weapons, ammunition and attachments.
- Disables some recipes from other mods and extends a few item tags.

## Requirements

- Minecraft **1.20.1**
- **Winterheart** (mod), for the items and recipe types.
- **Timeless and Classics Zero** and **No Tree Punching** (mods).

## Installation

The Winterheart modpack already includes it. To install it by hand, put the folder or zip in the world's `datapacks/` folder, or in the instance's `datapacks/` folder when the PackFinder mod is installed.
