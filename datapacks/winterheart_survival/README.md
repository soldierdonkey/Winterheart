# Winterheart: Survival Data

**Cold-survival balance for the Winterheart modpack.**

Minecraft 1.20.1 datapack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Sets Legendary Survival Overhaul temperatures for biomes, blocks, armor, held items, food and fuel, and thirst values for water and food.
- Changes what permafrost drops.
- Tunes limb poisoning and the effects of standing near gore, warmth, furniture and foliage.

## Requirements

- Minecraft **1.20.1**
- **Legendary Survival Overhaul** and **Immersive Weathering** (mods).
- **Winterheart** and **Winterheart: Survival** (mods), for limb poisoning and proximity effects.
- **Butchery** (mod), for the gore block tags.

## Installation

The Winterheart modpack already includes it. To install it by hand, put the folder or zip in the world's `datapacks/` folder, or in the instance's `datapacks/` folder when the PackFinder mod is installed.
