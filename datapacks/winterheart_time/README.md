# Winterheart: Time Data

**Tuning for Winterheart's day and night cycle.**

Minecraft 1.20.1 datapack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Sets day and night speeds, day phases, wake-up effects, the sanity drain after midnight and the day the eternal night starts (`data/winterheart/time/config.json`).

## Requirements

- Minecraft **1.20.1**
- **Winterheart** and **Winterheart: Time** (mods). The pack does nothing without them.
- **Legendary Survival Overhaul** (mod), for the wake-up effects.

## Installation

The Winterheart modpack already includes it. To install it by hand, put the folder or zip in the world's `datapacks/` folder, or in the instance's `datapacks/` folder when the PackFinder mod is installed.
