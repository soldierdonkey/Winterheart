# Winterheart: Butchery Fixes

**Makes sulfuric acid and hammers work on the Butchery blocks they skipped.**

Minecraft 1.20.1 datapack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Sulfuric acid turns horse carcasses, zombie horses included, into a skeleton horse carcass.
- Sulfuric acid turns wolf carcasses into a wolf skeleton.
- A hammer breaks iron golem heads, plain or repaired, into redstone and iron.

It only adds block tags that Butchery reads and doesn't fill.

## Requirements

- Minecraft **1.20.1**
- **Butchery** (mod), built against 5.2.

## Installation

The Winterheart modpack already includes it. To install it by hand, put the folder or zip in the world's `datapacks/` folder, or in the instance's `datapacks/` folder when the PackFinder mod is installed.
