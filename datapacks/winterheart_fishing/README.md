# Winterheart: Fishing Data

**Fishing settings for the Winterheart modpack.**

Minecraft 1.20.1 datapack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Sets how fish react to a bobber, how casts charge, and what can be caught (`data/winterheart/fishing/config.json`).

## Requirements

- Minecraft **1.20.1**
- **Winterheart: Fishing** (mod), which reads the file.

## Installation

The Winterheart modpack already includes it. To install it by hand, put the folder or zip in the world's `datapacks/` folder, or in the instance's `datapacks/` folder when the PackFinder mod is installed.
