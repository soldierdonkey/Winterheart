# Winterheart: Assets

**Item models and names used by the Winterheart modpack.**

Minecraft 1.20.1 resource pack by soldierdonkey2, made for the Winterheart modpack.

## What it does

- Gives each Winterheart guide book its item model.
- Gives Butchery's skinning knives, cleavers, hacksaws and hammers 3D models.
- Provides English names for Streams Reflowing biomes, blocks and settings.

## Requirements

- Minecraft **1.20.1**
- **Winterheart** and **Winterheart: Guides** (mods), for the guide books.
- **Streams Reflowing** (mod), for its names.
- **Butchery** (mod), for its tool models.

## Installation

The Winterheart modpack already includes it. To install it by hand, put the folder or zip in `resourcepacks/` and enable it.
