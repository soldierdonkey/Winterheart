# Changelog

## 1.0.0 - First release

Minecraft 1.20.1, Forge 47+. Requires PlayerAnimator 1.0.2-rc1+1.20 or newer.

### Added
- Seppuku animation (converted from Epic Fight: Dawn Day, used with Nexo's permission), synced to every player who can see it.
- `/seppuku play <targets> [animation]` and `/seppuku stop <targets>` (permission level 2).
- Server-side API `io.github.soldierdonkey2.seppuku.SeppukuApi.play/stop` for KubeJS.
